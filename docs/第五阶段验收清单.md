## 模型小样的执行条件

开始付费调用前，落实以下输入并登记到受控本机记录，不放入 Git：

1. 四通道凭据由环境或密钥服务注入，获准用途和可用型号明确。
2. 每个 provider/model 的价格版本、输入／输出整数单价、币种及单位含义明确；`site-credit` 不等于法币保障。
3. 管理员配置 `project/platform` 及适用个人日额，班级负责人配置所属教学／学生日额。明确本次最大调用数与总额度。
4. 测试材料有来源、外发许可、必要脱敏和最小片段；不外发真实学生身份和原始个人资料。
5. 执行 `python -m app.deployment_check --profile production --require-models`，处理阻断项；再按部署环境核对预算和凭据权限。

每个用途至少保存：源代码提交、脱敏样本编号、业务 job/call ID、实际 model/high、输出校验、是否截断、时延、usage、价格版本、站内扣减和供应商账单对应项。只保存必要公开结果和账务元数据，不留隐藏推理、密钥、Cookie 或未脱敏输入。

教师出题／审题和学生对话使用 Sol/high；评分与总结使用 Terra/high。客观题评分保持本地规则；受限提示和冻结总结仍须通过有限代码／事实校验。缺失 usage、超时或中断要按原调用 ID 核对，不按零费用或未执行处理，不自动重发。

## 故障验收记录

| 场景 | 必须观察的结果 |
| --- | --- |
| POST 回执丢失 | 本地保留原文本和请求 ID；明确操作后仅重放原载荷；服务端只保存一次 |
| 草稿保存与续租同时断网 | 临时网络失败不伪装为明确租约冲突；相同保存请求可确认原结果；明确过期／接管仍被拒绝 |
| 中文输入确认期间异步刷新 | 最终汉字、输入框可见值和发送内容一致；选区及滚动保持合理 |
| 回答流中断后重连／刷新 | 读取同一回答的权威 snapshot 与已持久事件，不再次 POST 消息 |
| 已发送后重启／超时 | 保留 unknown／cost_pending，核对结果与费用后明确确认恢复；不二次扣费采用已有结果 |
| 取消 | 正文投影与继续采用被阻断，保留已发生费用；取消后的恢复入口拒绝 |
| 未发送草稿／发送结果未知时离页 | 正常离页或刷新请求浏览器确认；取消离开后原请求仍可恢复 |

实际浏览器若不支持故障注入、控制台或真实 IME 事件，记录为未覆盖。运行时能力不足时不能通过注入页面状态模拟成功。

## 后置兼容性与公开部署签收

用户已明确其他样式、手机、其他尺寸／比例和跨设备兼容性排到最后，本轮不再为这些项目扩大改动。后续实机记录至少包含设备／系统／浏览器版本、输入法、竖屏／横屏、键盘弹出／收起、长文输入、发送按钮和底栏可达性、断网恢复、结果截图。历史低高度视口观察只作为当时的部分布局证据。
