## 本地运行

要求 Python 3.11+。首次安装（仓库根目录）：

```powershell
cd server
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd ..
.\start_study_companion.bat
```

访问 <http://127.0.0.1:8000/>。后续双击根目录 `start_study_companion.bat` 即可；窗口保持运行，Ctrl+C 停止。可用 `STUDY_COMPANION_PORT` 指定端口。服务仅绑定 `127.0.0.1`，是本地演示配置。

从任意目录手动启动时须给出应用目录；在仓库根目录可用：

```powershell
.\server\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir server --host 127.0.0.1 --port 8000
```

`/health` 返回 `offline-sample`、`storage=sqlite` 和上游标识。师生按钮是虚构样例的视角切换，不是真实身份验证。

当前机器初次在线安装在 jieba 下载处停滞；本次通过 `python -m venv --system-site-packages server/.venv` 复用机器上已有依赖，全部满足 `requirements.txt`。`.venv` 不提交；其他机器按上述普通安装步骤建立独立环境。

## 样例与持久化

`server/app/services/study_demo.py` 确定性生成 50 名虚构学生，覆盖三个主题、八个知识点。原 `demo/` 保留为静态原型快照，`web/` 从服务端获取统计、优先项和材料建议。教材位置、作答过程、微课和练习材料都是样例登记，不代表已导入官方资料或真实视频。

- 有效记录少于 3 条：依据不足。
- 有足够记录时，正确率低于 50%：薄弱；50% 至低于 80%：待巩固；80% 及以上：已掌握。
- 先按状态、正确率和记录数选优先项；错误频次并列时取最近出现的题目。
- 建议材料关联最常出现的错题讲解，无错题时选基础练习。
- 学生 07 的固定案例与入口例题对应，去括号记录为 2/6，展示错步和建议。

阈值仅为当前演示规则，不代表官方诊断口径或经教学验证的能力结论。新提交练习单独保存，不改变固定历史诊断，不据此宣称教学效果。

默认持久化路径为 `server/data/study/store.sqlite3`，复用上游 SQLite 压缩快照。练习最后选项与回顾、安排、任务、提交、反馈保存在独立 `teaching_state`，清空报告缓存不会删除事实。旧 `reports["study-practice"]` 自动迁为已知最后选项，并保留原始恢复副本，不补造时间、次数或教师安排。可在 `server/.env`（模板见 `.env.example`）设置 `STUDY_DATA_DIR` 或 `STUDY_PERSISTENCE_ENABLED=false`；相对数据路径按 `server/` 定位。数据库不可读时拒绝初始化，保存失败返回 503 并还原内存。只启动一个应用进程，不使用多个 worker。

JSON 成果包含 `learning_contents`、`learning_analysis`、`learning_recommendations`、材料、证据记录及字段说明；CSV 每个学生/知识点一行，带 UTF-8 BOM。班级页导出当前主题全班数据，个人报告导出当前学生全部主题，不应用界面中的姓名/状态显示筛选。

## 网络与资料边界

新增样例流程不发出外部请求，无模型密钥也可运行。保留的 LLM/MaxKB 适配器只接受 HTTP/HTTPS，发请求前检查主机所有解析地址，拒绝 localhost、环回、私有、保留和组播地址，并关闭自动重定向与环境代理。请求固定到已验证的 IP，保留原 Host 与 TLS SNI，避免校验后重新解析域名。未验证真实模型服务，不应宣称已有模型生成能力。

正式赛事资料、原始文件、报名材料、截图、密钥、数据库和运行产物继续留在忽略范围。当前未导入正式赛事包，未完成三名正式代表案例、两班比较或独立评测；样例机读文件不是正式赛事成果。
