# 赛题要求与数据边界

整理日期：2026-11-04。本文根据此前核对的本地第10题规则和报名通知整理，是团队工作笔记，不替代赛事正式规定。

## 作品必须完成的内容

规则PDF第3—4页（文件页码）要求：参赛团队基于赛题组提供的课程标准相关材料、配套学习材料与模拟学情数据，打造“智慧学伴”智能体，完成三项核心任务。

1. **学习内容与要求梳理**：整理指定范围内的学习内容、要求、必要联系和材料出处。
2. **学生学习情况分析**：整理和检查模拟学情数据，形成个体与群体摘要，保留记录或统计依据。
3. **个性化学习建议**：给出具体学习内容、练习或活动，说明对应材料、理由和必要顺序。

缺少记录不等于答错或未掌握；分析必须与实际提供的字段匹配。

## 统一数据的约束

规则PDF第8页写明，统一课程要求材料、配套学习材料与模拟学情数据，是全体参赛队伍完成三项任务的基础。因此，不能把完全脱离赛方资料的通用学习应用直接视为完成本题。

允许作品支持其他数据和场景，但参赛成果仍应能够使用赛方资料完成规定任务。第9页允许按规则补充公开学习材料，需要登记来源、用途与引用位置；第7页还要求对其他公开数据登记来源、采集时间、方式和合规自查结论。禁止自行引入真实学生个人信息。

本地未发现正式数据包，不能由此断言官方尚未发布。获取方式、版本、使用说明和更新以官方渠道与赛题答疑为准。

## 已公布的参考范围

以下是规则中的拟定范围及参考规模，不是已经收到的数据清单。

| 模块 | 参考范围 |
| --- | --- |
| 学习主题 | 首批拟为七年级数学，2—3个相关主题 |
| 配套学习材料 | 约60道题目或学习材料 |
| 模拟学生 | 约20—50名，组成若干群体 |
| 学习记录 | 约300—1,000条 |
| 说明文件 | 学习任务条件、数据字典与使用说明 |
| 独立评测 | 拟另行准备约10—20名模拟学生、100—400条记录 |

主题、材料数量、记录规模与字段均以正式数据包为准。独立评测的测试方式、时间和提交要求另行公布。

## 企业选拔赛交付

- 设计方案PDF：不超过20页。
- 任务成果包：含三项任务结果；结构化结果采用JSON、CSV等可机读格式，附字段说明、输入输出样例和操作说明。
- 演示视频：MP4，5分钟以内。
- 分析脚本或代码：可选；无论是否交代码，都需提供足以核对关键结果的样例与说明。
- 现场答辩PPT：讲解10分钟，答辩5分钟。

材料评审占80%，现场答辩占20%。技术栈不限定，不以使用某种特定技术为得分前提。
