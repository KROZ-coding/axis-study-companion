# 伴星导学 · 全流程演示操作指南

这个版本供本机演示。你自行录制屏幕，程序不包含录屏功能。

代码仅保存在 `demo/recording-only-do-not-merge` 分支，禁止合入正常代码。正常开发使用 `docs/competition-production-direction`；切换回来演示时再选择此演示分支。

## 启动

双击仓库根目录的 `start_recording_demo.bat`，保留弹出的窗口，再访问：

<http://127.0.0.1:8010/prototype/>

页面顶部展开“演示工具”，可切换教师陈宁、学生林夏、学生周予，无需输入口令。切换仍建立正式账号会话。每次启动创建新的独立演示数据目录，原有 `demo2` 和以前的演示记录保持不变。

如果 8010 已有此演示服务，直接打开页面即可；若被其他程序占用，可以运行 `start_recording_demo.bat --port 8011`，然后使用对应端口。不要重复双击启动多个服务。关闭窗口或按 Ctrl+C 停止服务。

## 建议演示顺序

建议浏览器全屏，缩放 100%，先熟悉一次流程再正式录制。顶部工具可以收起；页面保留演示来源说明。

1. **教师介绍目标。** 在演示工具选择“教师 陈宁”，查看班级学情和课程题库。首次启动已有一个待完成目标；需要重新演示时，点击“开始新一轮”。该按钮实际创建并发布目标，保存旧轮记录。正式“下发目标”抽屉也可以使用已备题库完成预览和发布，录制时采用一种发布方式即可。
2. **林夏完成首诊。** 切换“学生 林夏”，进入“任务”，打开最新目标。两道首诊独立完成；可在一题选择“暂时不会”，另一题正常回答，点击“提交短诊”。展示首诊不计入正式成绩和简短反馈。
3. **林夏先尝试，再求助。** 正式练习共四题。选择第一题答案后，展开“演示辅导”，点击“要一步提示”；补充追问再点“继续追问”，展示循序引导。提示记录会真实保存。返回作答后继续完成其他题，点击“确认交卷”。
4. **展示反馈。** 等待实际后台评分，查看首次成绩、逐题解析和“接下来怎样学”。客观题采用原程序判分，预置简答采用明确标记的演示规则评分。可以说明“分数、提示使用和长期掌握是不同信息”。
5. **周予展示不同路径。** 切换“学生 周予”，完成首诊后独立作答，不使用提示。交卷后展示其成绩和建议。两人的差异来自实际输入和求助记录，不预先制造成绩。
6. **教师指导。** 回到教师，打开对应学生的依据页，查看真实得分，填写并“发送短评”。切回该学生，在任务结果页的“与老师交流”中查看短评并“回复老师”。双方消息真实保存。
7. **生成成果。** 切回教师，打开“阶段成果”，选择“学习目标执行”及本轮目标，点击“生成报告”。展开学习判断和逐题证据，展示提示使用与独立作答的差异。点击 PDF、Excel、JSON、CSV 或网页下载；也可以切换班级、个人、题库报告后重新生成。

五分钟视频可把实际输入加速，只保留一次提示、一次评分反馈、一次短评和一份报告的完整操作。不要在视频中把模拟辅导描述为真实模型调用。

## 演示输入参考

以下供操作人员排练，不会自动填写学生答案。可以先复制简答文本到自己的笔记，录制时再粘贴到作答框。

| 环节 | 题目 | 正确作答参考 |
| --- | --- | --- |
| 首诊 1 | 由 x + 2 = 7，两边同时怎样操作？ | 减 2 |
| 首诊 2 | 到原点的距离可以是负数？ | 错误 |
| 正式选择 | 3x = 12 | x = 4 |
| 正式判断 | 零的绝对值是负数？ | 错误 |
| 正式填空 | x + 5 = 9 | 4 |
| 正式简答 | 解 2x + 3 = 11 并检验 | 两边减去3得2x=8；两边除以2得x=4；代入2×4+3=11，成立。 |

例如林夏可在判断题选“正确”，简答先只写“2x=8，x=4”；周予使用表中完整解答。这样差异由实际作答产生，林夏的简答得到部分分，周予的完整步骤得到全分。演示简答规则只覆盖预置题，不能代表通用语义评分质量。

建议短评：“你已经找到等式两边同时变形的方法。下一次请补上代入检验，并独立完成一道新题。”

建议学生回复：“我会把检验步骤补齐，下一轮先独立尝试，再决定是否求助。”

## 真实与模拟范围

| 能力 | 演示方式 |
| --- | --- |
| 账号会话、课程、班级、目标发布 | 正式业务逻辑，独立演示数据 |
| 首诊、草稿保存、交卷、求助记录、短评回复 | 真实保存 |
| 选择／判断／支持的填空评分 | 正式程序评分 |
| 预置简答评分 | 本机量表规则模拟，判定文案注明来源 |
| 逐步辅导、默认自由学伴、结果建议 | 本机模拟或确定性规则，界面明确标记 |
| 四类报告、五种输出 | 正式报告接口，基于实际保存记录 |
| 人物与课程 | 新编虚构样例，不是正式赛事数据或真实学生资料 |

默认启动不读取 `server/.env`，不发送付费模型请求。现有正式模型通道保留；需要真实模型时，必须已在进程环境中配置相应模型、单价和预算，再用 `--allow-live` 明确启用。正式在线聊天仍受原有任务、首诊、外发和费用策略约束，不能只配置密钥就保证成功。本演示的分步提示和预置简答规则仍会按模拟标注。

## 重来与常见情况

- **想重新演示：** 教师点击“开始新一轮”，然后学生选择最新任务。旧成绩不删除，历史保留；需要完全空白的运行可停止后重新启动。
- **提示要求先尝试：** 先在当前题选项或文本框给出自己的尝试，再点击提示。首诊期间不能请求解题提示。
- **报告无记录或待评估：** 确认学生已经交卷且评分结束，再刷新范围并生成报告。少量题目不能形成稳定掌握结论，“待评估”是正常结果。
- **需要重复录制某一段：** 使用新一轮保留前一轮记录，不通过删除数据库重置。
- **服务窗口关闭后页面报错：** 重新启动演示并刷新网页。新启动会创建新的独立运行，旧运行数据仍保存在本机。

运行数据位于 `server/data/recording-demo/run-*`，被 Git 忽略。不要把该目录、Cookie、口令或真实模型凭据上传到仓库或放进视频。
