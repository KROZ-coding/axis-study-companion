## 2. 旧约定冲突处置

| 主题 | 旧描述可能导致的偏差 | 本轮采用的最新口径 |
| --- | --- | --- |
| 制作顺序 | 旧计划先视觉但已做过后端；后续误以为当前后端足够 | 先P0可点击原型，新产品权限/队列/AI等另行实施 |
| 视觉 | 纸色楷体小圆角、禁止3D、仅入口等少数动效 | 冰蓝通透玻璃贯穿，登录3D互动，关键动作动效；阅读可用性保留 |
| 身份 | 本地X-Demo选择师生 | 正式统一账号登录，演示空间与正式权限隔离 |
| 角色复核 | 所有任务都等待教师确认完成 | AI核实形成阶段结果，只有争议/失败/教师介入需人工处理 |
| 题库生成 | 推荐多家模型或教师逐题放行 | 已固定Sol/Terra；合格题自动入库，抽检不改为逐题批准 |
| 动态个性化 | 学习途中随时换题或明显按能力分层 | 开始前定卷整轮固定，讲解提示不同，题量难度接近 |
| 问题题处理 | 早先“自动纠正全部结果” | 自动保护性暂停与证据暂排除，教师确认正式更正 |
| 报告纠正 | 历史快照不变就不更新默认报告 | 原快照不变，新修订成为默认；旧下载件提示有新版本 |
| AI总结时效 | 每条新作答/改分都重写长总结 | 数值/当前学情更新，长总结提示过期，教师按需重生 |
| 重做 | 只允许教师要求重试 | 学生可多次自行重做，首次成绩主展示，已见答案非独立证据 |
| 评分开放 | 单题提交立刻揭答案 | 整轮提交、完整评分后统一揭示；总结失败不阻挡成绩 |
| 到期 | 关闭即自动交空白或只能全班延长 | 保留草稿未交，可个别/全班延期，迟交/重做开关提前确定 |
| 首版格式 | 将PDF/Excel推迟或Excel等于CSV | 四类报告的网页、PDF、真实Excel、JSON、CSV均首版验收 |
| 离线 | 在线加本地就意味着离线AI/双向同步 | 最新要求首版本机联网跑通录视频，无离线同步前置 |
| 教师看日志 | 实际请求/返回明细等于完整学生会话 | 按业务资源授权，仍只必要片段和关键依据 |
| 重启 | 全部任务自动继续付费 | 已提交评分自动恢复，其余付费AI操作待确认 |

## 4. 未决事项的类别

- **可直接设计的默认**：时区、HTTP错误结构、幂等键、任务租约、格式schema、轮询/事件游标等，由技术方案说明，不重复当用户偏好询问。
- **需小样校准**：掌握度阈值权重、难度可比性、响应速度、并发和预算默认值、语音/公式识别范围。
- **需外部证据**：正式赛事课程和版本、外发许可、案例与评分参照、模型线路能力/费用、运行设备和真实试用授权。
- **需原型确认**：内页实际构图、信息密度、触控体验、材质、动效及减少动态回退。

以上在总方案§17 O-01–O-08登记。可点击原型不因所有外部条件未齐而停止；真实教学数据、付费调用和正式成果验收必须满足对应条件。
