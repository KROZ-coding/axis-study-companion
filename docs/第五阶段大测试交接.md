## 第一轮：完整隔离回归

在仓库根目录使用项目Python虚拟环境和Node运行。下列PowerShell命令不安装依赖、不读取真实`.env`，不发起真实模型调用：

```powershell
.\server\.venv\Scripts\python.exe -I -B -X utf8 server/tests/run_tests.py
$regressions = Get-ChildItem server/tests/*regression.cjs | Select-Object -ExpandProperty FullName
node --test $regressions
```

通过标准：两者退出码均为0；Python无失败／错误，Node无失败或取消，跳过项目逐项说明。记录实际计数、时长、代码基线及本地未提交差异。不能根据旧计数推算新总数。

三套真实应用回环HTTP分别运行，输出目录必须使用`.scratch/`下尚不存在的新目录；将下面`RUN-NEW`替换为本次独立编号：

```powershell
.\server\.venv\Scripts\python.exe -I -B -X utf8 server/tests/run_platform_flow.py --output-dir .scratch/stage5-platform-RUN-NEW
.\server\.venv\Scripts\python.exe -I -B -X utf8 server/tests/verify_companion_live.py --output-dir .scratch/stage5-companion-RUN-NEW
.\server\.venv\Scripts\python.exe -I -B -X utf8 server/tests/verify_teaching_loop.py --output-dir .scratch/stage5-teaching-RUN-NEW
```

通过标准：各自`evidence.json`为passed、无失败、全部必需阶段完成；平台持续计划保留真实60秒间隔，恢复后六库／附件哈希及历史报告一致；原实例与恢复实例均须退出码0、`graceful: true`且worker为0，不能把Windows强制终止当作正常停服。学伴SSE重读同一回答，客户端帮助请求不能伪造送达；教学闭环不重复调用已有成功结果，取消后不继续采用提示。检查临时凭据／数据库清理；请求数含轮询，不要求与历史请求数恰好相等。

完整Python会自动发现`test_model_gateway_loopback.py`与`test_grading_model_flow.py`。前者需要本机`openssl`生成临时CA／叶证书；缺失时必须登记跳过，不能算协议验收通过。后者只用MockTransport代替供应商HTTP，实际执行Runtime、SQLite、Worker和计费。两者均不得继承真实`.env`、凭据或模型线路。

## 第二轮：真实模型、费用与恢复

先按[模型接入约定](模型分工与接入约定.md)和[第五阶段验收清单](第五阶段验收清单.md)落实凭据、价格版本、币种、适用预算及本次总调用上限。凭据经环境或密钥服务注入，配置只保存`api_key_env`引用，不把秘密放入命令行、日志或仓库。

在`server/`目录、同一获准配置环境中运行：

```powershell
$env:SKIP_ENV_FILE = "1"
.\.venv\Scripts\python.exe -B -m app.deployment_check --require-models
```

生产实例再加`--profile production`。该命令只验证配置；预算余额、线路权限和供应商账单须另查。价格或适用预算缺失、币种不匹配时必须阻断发送。

| 样本／场景 | 应观察到的结果 |
| --- | --- |
| 教师生成／审题 | 正式teacher通道、Sol/high；输出按业务校验，来源及版本保留 |
| 学生自由对话／正式题提示 | 正式student通道、Sol/high；自由聊天按答案政策，hint只接受action_id并由服务器模板显示 |
| 简答评分 | 显式grading通道、Terra/high；不能用客观题本地规则评分冒充真实模型验收 |
| 冻结报告总结 | 显式summary通道、Terra/high；完整冻结facts、学生及证据不能被模型改写 |
| 缺失通道／价格／额度 | 在发往供应商前阻断；不静默回落到其他通道、旧客户端或型号 |
| POST回执丢失／流中断 | 沿用原request_id或GET读取同一回答；不重新创建消息／调用 |
| 发送后重启／usage未知 | 保留unknown、cost_pending或对账门禁，依据原call核对，不按零费用或未执行处理 |
| 核对完成后恢复 | 原作业仍需明确确认；已成功call／checkpoint复用，不重复发起付费 |
| 取消 | 隐藏不再允许采用的提示，公共恢复拒绝，保留已发生和待核对费用 |

每个用途记录：脱敏样本编号、purpose/channel、供应商与型号、high请求配置、job/call ID、输出校验、时延、输入／输出usage、价格版本、站内实际扣减和账单对应项。隐藏推理、密钥、Cookie、激活码、原始学生资料不得写入验收包。
